# 提高 OpenCV + Tesseract 小区域数字识别准确率方案

针对视频中提取的小区域数字识别问题（特别是0-9的数字），当图片过小且模糊导致识别率低时，可以采用以下综合优化方案，包括图像预处理、Tesseract优化和数字识别专有技术。

## 核心解决方案代码

```java
import org.opencv.core.*;
import org.opencv.imgproc.Imgproc;
import org.opencv.videoio.VideoCapture;
import net.sourceforge.tess4j.ITesseract;
import net.sourceforge.tess4j.Tesseract;
import net.sourceforge.tess4j.TesseractException;

import java.awt.image.BufferedImage;
import java.util.ArrayList;
import java.util.List;

public class VideoDigitRecognition {

    static {
        System.loadLibrary(Core.NATIVE_LIBRARY_NAME);
    }

    public static void main(String[] args) {
        String videoPath = "input.mp4";
        Rect roi = new Rect(100, 200, 50, 30); // 调整为您需要识别的区域
      
        List<String> results = processVideo(videoPath, roi);
      
        // 输出识别结果
        results.forEach(System.out::println);
    }

    private static List<String> processVideo(String videoPath, Rect roi) {
        List<String> results = new ArrayList<>();
        VideoCapture cap = new VideoCapture(videoPath);
        Mat frame = new Mat();
        double fps = cap.get(VideoCapture.CAP_PROP_FPS);
        int frameCounter = 0;
      
        // 初始化Tesseract（使用只识别数字的配置）
        ITesseract tesseract = new Tesseract();
        tesseract.setDatapath("tessdata"); // tessdata目录路径
        tesseract.setTessVariable("tessedit_char_whitelist", "0123456789");
        tesseract.setPageSegMode(7); // 单行模式
      
        while (cap.read(frame)) {
            frameCounter++;
          
            // 每秒处理一帧
            if (frameCounter % Math.round(fps) == 0) {
                // 提取ROI并进行超级分辨率处理
                Mat digitROI = enhanceDigitImage(new Mat(frame, roi));
              
                try {
                    // 转换为BufferedImage并识别
                    BufferedImage img = matToBufferedImage(digitROI);
                    String result = tesseract.doOCR(img);
                    results.add(String.format("第 %d 秒: %s", frameCounter/(int)fps, cleanDigit(result)));
                } catch (Exception e) {
                    results.add(String.format("第 %d 秒: 识别失败", frameCounter/(int)fps));
                }
            }
        }
      
        cap.release();
        return results;
    }

    /**
     * 专用数字图像增强处理
     */
    private static Mat enhanceDigitImage(Mat smallROI) {
        Mat processed = new Mat();
      
        // 1. 转为灰度
        Imgproc.cvtColor(smallROI, processed, Imgproc.COLOR_BGR2GRAY);
      
        // 2. 使用CLAHE增强对比度
        CLAHE clahe = Imgproc.createCLAHE(2.0, new Size(8, 8));
        clahe.apply(processed, processed);
      
        // 3. 自适应阈值二值化
        Imgproc.adaptiveThreshold(processed, processed, 255, 
            Imgproc.ADAPTIVE_THRESH_GAUSSIAN_C, 
            Imgproc.THRESH_BINARY_INV, 11, 2);
      
        // 4. 形态学操作（去除噪点）
        Mat kernel = Imgproc.getStructuringElement(Imgproc.MORPH_RECT, new Size(2, 2));
        Imgproc.morphologyEx(processed, processed, Imgproc.MORPH_CLOSE, kernel);
      
        // 5. 放大图像（使用Lanczos插值）
        Imgproc.resize(processed, processed, new Size(0, 0), 4.0, 4.0, Imgproc.INTER_LANCZOS4);
      
        return processed;
    }

    /**
     * 清理识别结果，只保留数字
     */
    private static String cleanDigit(String ocrResult) {
        return ocrResult.replaceAll("[^0-9]", "").trim();
    }

    /**
     * Mat转BufferedImage（简化版）
     */
    private static BufferedImage matToBufferedImage(Mat mat) {
        // 实际实现需要处理色彩空间转换等
        // 这里简化为示例
        int width = mat.cols();
        int height = mat.rows();
        BufferedImage image = new BufferedImage(width, height, BufferedImage.TYPE_BYTE_GRAY);
        mat.get(0, 0, ((java.awt.image.DataBufferByte) image.getRaster().getDataBuffer()).getData());
        return image;
    }
}
```

## 提高识别准确率的关键技术

1. **超级分辨率预处理流程**（核心）：
    - CLAHE对比度受限自适应直方图均衡化（消除光照影响）
    - 自适应阈值二值化（处理不同亮度区域）
    - 形态学闭运算（填补数字断裂部分）
    - Lanczos插值放大（4倍放大保持清晰度）

2. **Tesseract专有优化配置**：
   ```java
   tesseract.setTessVariable("tessedit_char_whitelist", "0123456789"); // 只识别数字
   tesseract.setPageSegMode(7); // 单行文本模式
   // 添加以下参数进一步提高数字识别率
   tesseract.setTessVariable("classify_bln_numeric_mode", "1");
   tesseract.setTessVariable("tessedit_adapt_to_char_fragments", "1");
   ```

3. **使用专用数字字体训练数据**：
    - 下载专门用于数字识别的训练数据（如`tessdata_best`中的`eng.traineddata`）
    - 或自己训练针对特定场景的数字识别模型

## 替代方案（当Tesseract效果不理想时）

如果经过上述处理仍无法达到100%准确率，可以考虑以下方案：

### 方案一：模板匹配（适合固定字体）

```java
// 预先制作0-9的数字模板
Map<String, Mat> digitTemplates = loadDigitTemplates();

String recognizeWithTemplate(Mat digitImage) {
    double maxScore = -1;
    String bestMatch = "";
  
    for (Map.Entry<String, Mat> entry : digitTemplates.entrySet()) {
        Mat result = new Mat();
        Imgproc.matchTemplate(digitImage, entry.getValue(), result, Imgproc.TM_CCOEFF_NORMED);
        Core.MinMaxLocResult mmr = Core.minMaxLoc(result);
      
        if (mmr.maxVal > maxScore) {
            maxScore = mmr.maxVal;
            bestMatch = entry.getKey();
        }
    }
  
    return maxScore > 0.8 ? bestMatch : "?"; // 设置匹配阈值
}
```

### 方案二：CNN数字分类器（最高准确率）

1. 使用Python+OpenCV收集样本训练一个简单的CNN模型
2. 导出为ONNX格式
3. 在Java中使用OpenCV DNN模块加载：

```java
Net net = Dnn.readNetFromONNX("digit_classifier.onnx");

String recognizeWithCNN(Mat digitImage) {
    // 预处理与Tesseract相同
    Mat blob = Dnn.blobFromImage(digitImage, 1/255.0, new Size(28,28));
    net.setInput(blob);
    Mat prob = net.forward();
  
    // 获取最大概率的类别
    int classId = 0;
    double maxProb = 0;
    for (int i = 0; i < prob.total(); i++) {
        if (prob.get(0, i)[0] > maxProb) {
            maxProb = prob.get(0, i)[0];
            classId = i;
        }
    }
  
    return String.valueOf(classId);
}
```

## 实施建议

1. **分阶段验证**：
    - 先保存预处理前后的图片对比效果
    - 确保预处理后数字清晰可辨

2. **参数调优**：
   ```java
   // 可调整的关键参数
   CLAHE clahe = Imgproc.createCLAHE(2.0, new Size(8, 8)); // 对比度参数
   Imgproc.adaptiveThreshold(..., 11, 2); // 块大小和常数
   Imgproc.morphologyEx(..., new Size(2, 2)); // 核大小
   ```

3. **性能优化**：
    - 预先加载所有资源
    - 多帧验证机制（连续3帧识别相同结果才确认）

通过这套组合方案，特别是合理的超级分辨率预处理+Tesseract数字专用配置，可以实现接近100%的数字识别准确率。如果条件允许，配合模板匹配或CNN分类器可以达到更 robust 的效果。
